# Pattern Printing using Nested Loops

When creating programs to print patterns, the general approach involves using **nested loops**. Here are the fundamental rules to follow:

## Rules

1. **Determine Rows (Outer Loop):** Count how many rows are required for the pattern. This will be the condition for your outer loop.
2. **Determine Columns (Inner Loop):** Focus on the columns for each row. Find the mathematical or logical relationship that connects the number of columns (or the characters to print) with the current row number. This defines your inner loop.
3. **Print Elements:** Execute your print statement inside the inner loop to display the pattern elements (stars, numbers, spaces, etc.). Remember to print a new line after the inner loop finishes to move to the next row.
